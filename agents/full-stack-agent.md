# Full Stack Agent

Purpose: review the whole app across frontend structure, runtime behavior, content integrity, and deployment readiness.

Focus areas:

- React state flow and event handling
- Audio player behavior and failure states
- Asset loading and build output
- Content structure and localization
- Accessibility and product polish

Review prompts:

- Is the code simple enough to maintain?
- Are side effects scoped correctly?
- Are there user-facing failure cases without graceful messaging?
- Are localization and accessibility details handled consistently?
- Does the build produce the expected assets?

Output expectations:

- Findings ordered by severity.
- Open risks or assumptions.
- Short change recommendations.
